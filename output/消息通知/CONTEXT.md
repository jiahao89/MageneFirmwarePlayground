# 消息通知 · 领域术语表（CONTEXT）

> 只放术语定义，不放实现细节。grill 三轮后全部定型。

| 术语 | 定义 | 状态 |
|------|------|------|
| 消息通知 | 手机上的来电、短信及第三方应用通知经 App 传递至码表的功能总称 | ✅ |
| 通知事件 | 一条进入码表的通知，是消息列表的存储单位（逐条占位，不聚合） | ✅ |
| 消息列表 | 负一屏最后一页的通知记录，时间倒序，满容量移除最早；RAM 易失，掉电/重启清空（ADR 0001） | ✅ |
| 列表容量 | C706 与 C716/C716 Pro 为 20 条，6 系为 5 条 | ✅ |
| 消息静音 | 原 C706 勿扰模式。关通知弹窗**与通知音**，消息仍进列表。默认关闭。只管消息通知这一类 | ✅ |
| 勿扰模式 | 骑行专注模式。屏蔽声音与部分弹窗，声音按钮静音且不可调 | ✅ |
| 勿扰白名单 | 勿扰下保留的弹窗：防盗警报、低电量告警、结束骑行确认、转向/偏航导航；不保留：智联、普通通知、赛段提醒 | ✅ |
| 来电 | 手机通话呼入，通知体系中最高优先级。正常亮屏响铃+弹窗；熄屏/休眠/静音/勿扰/长续航不响不亮不弹、仅进列表 | ✅ |
| 新消息条数 | 弹窗展示字段，= 同 App 未读消息聚合（App 下发），不占列表位；显示上限 99+ | ✅ |
| 显示字符位 | 截断单位：CJK 1 位、ASCII 0.5 位，超出省略 + "…"（不滚动）。弹窗内容 10 位、App 名称 10 位、联系人/群名 12 位 | ✅ |
| 详情页 | 消息条目点开后的完整视图：全量展示协议下发正文、可滚动、不截断 | ✅ |
| 断连暂存 | BLE 断连期间 App 侧暂存通知的机制，上限 20 条，回连补推最新一批 | ✅ |
| 海外通知源 | KakaoTalk（已立项）与 Line，均仅海外版独立开关，国内版不展示 | ✅ |
| 状态矩阵 | 熄屏/休眠/静音/勿扰/长续航五态统一定义：消息一律写列表，差异只在声音/唤醒/弹窗 | ✅ |
| 弹窗全局优先级 | 安全预警 > 核心指令 > **导航引导** > 骑行辅助 > **通知提醒（来电>普通通知）** > 事务操作 > 操作指引 > 状态反馈（导航提到通知之上，ADR 0002） | ✅ |
| 勿扰安全预警 | 勿扰下安全预警（低电量告警/关机提醒）保留弹窗**且保留声音**；其余通知全静默（PM 覆盖 benchmark「全量屏蔽声音」） | ✅ |
| 勿扰白名单 | 勿扰下保留：低电量告警、关机提醒、结束骑行确认、转向/偏航导航；不保留：智联、普通通知、赛段提醒 | ✅ |
| BLE 链路优先级 | 安全预警 > 来电 > 普通通知 > 音乐控制 > 配置同步（后台最低）；产品定档位+最坏延迟（安全预警 < 500ms），队列/背压归固件 | ✅ |
