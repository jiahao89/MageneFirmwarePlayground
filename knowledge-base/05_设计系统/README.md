# 产品设计系统

这是本项目唯一的正式设计规范入口。它支持三套彼此独立、可以直接用于原型生成的设计语言：

| 设计系统 | 适用范围 | 视觉与交互定位 |
| --- | --- | --- |
| [顽鹿 App](01_顽鹿App/设计规范.md) | OnelapFit 手机端 | 深色运动控制 App；适合设备管理、骑行服务、同步与 OTA 等复杂任务 |
| [迈金 C706](02_迈金C706/设计规范.md) | C706 码表端 | 浅色高对比数据界面；骑行中遵循“一眼原则” |
| [GEOID 极遨](03_GEOID/设计规范.md) | GEOID 码表端 | 深/浅双模式、年轻多彩；优先降低新手理解与操作成本 |

## 使用方式

1. 设计或评审前调用 `$magene-design`。
2. 明确目标系统、任务类型、工具；GEOID 还必须明确机型与显示模式。
3. 运行路由脚本并阅读全部 `Required reading` 文件。
4. 输出设计上下文卡后再开始出图；交付前按目标规范的自检项复核。

路由、冲突裁决和上下文卡见 [00_使用与路由.md](00_使用与路由.md)。跨 App 与码表的任务使用 [04_跨端流程规范.md](04_跨端流程规范.md)；工具操作使用 [05_工具适配](05_工具适配) 中的对应文件。历史文件与正式规范的映射见 [迁移说明.md](迁移说明.md)。

## 目录角色

本目录是**正式规范**。历史上的 `design system/` 与 `GEOID_Design/` 用于保留来源和迁移记录，不再作为 Agent 的设计决策入口。新增或修改规则只更新本目录，避免同一规则在多处维护。
