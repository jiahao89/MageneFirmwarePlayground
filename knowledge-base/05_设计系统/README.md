# 产品设计系统

本目录是 `magene-design` 的自包含正式设计规范。它支持四套彼此独立、可直接用于原型生成的设计语言：

| 设计系统 | 适用范围 | 视觉与交互定位 |
| --- | --- | --- |
| [顽鹿 App](01_顽鹿App/设计规范.md) | OnelapFit 手机端 | 深色运动控制 App；适合设备管理、骑行服务、同步与 OTA 等复杂任务 |
| [迈金](02_迈金C706/设计规范.md) | C706 码表端（当前主适配） | 浅色高对比数据界面；骑行中遵循“一眼原则” |
| [LowDesign](04_LowDesign/设计规范.md) | C706 码表端高保真探索 | Night Vector 深色硬件 UI；视觉优先，但保留 C706 的一眼可读与物理约束 |
| [GEOID 极遨](03_GEOID/设计规范.md) | GEOID 码表端 | 深/浅双模式、年轻多彩；优先降低新手理解与操作成本 |

## 使用方式

1. 设计或评审前调用 `$magene-design`。
2. 明确目标系统、任务类型、工具；跨端 `flow` 必须明确两个及以上目标系统；GEOID 还必须明确机型、像素尺寸与显示模式；LowDesign 固定为 C706 `320×480`、Night Vector 深色。
3. 运行 Skill 内的路由脚本，并阅读全部 `Required reading` 文件。
4. 输出设计上下文卡后再开始出图；交付前按目标规范的自检项复核。

路由、冲突裁决和上下文卡见 [00_使用与路由.md](00_使用与路由.md)。跨 App 与码表的任务使用 [04_跨端流程规范.md](04_跨端流程规范.md)；工具操作使用 [05_工具适配](05_工具适配) 中的对应文件。

本目录是本 Skill 唯一的正式设计规则来源。目标项目的 PRD 负责业务范围、状态和允许操作；项目规范与本 Skill 冲突时，应记录冲突并请产品负责人裁决。
