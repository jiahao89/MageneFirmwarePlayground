# LowDesign 设计规范

> **定位：** C706 平台的高保真视觉探索系统。`Low` 指低姿态、带一点自嘲，不指低完成度。正式气质是 **Night Vector**：深墨绿黑、精密数字、荧光黄绿焦点、冷蓝路线、克制的动态能量。
>
> **适用：** 已明确选择 LowDesign 的 C706 `320 × 480px` 页面、组件与高保真概念原型。它不是迈金正式系统的默认替代，也不能与顽鹿 App、迈金正式浅色系统或 GEOID 组件混用。

## 1. 不变的产品与安全约束

LowDesign 继承 C706 的硬件与安全边界；以下内容不是可选视觉风格：

| 区域 | 尺寸 / 规则 |
| --- | --- |
| Frame | 固定 `320 × 480px`；无纵向滚动、无裁切 |
| 系统状态栏 | `320 × 32px`；时间固定左侧，状态图标组靠右，电量图标与数值固定最右 |
| 内容区 | `320 × 448px`；可选 `48px` 子页标题栏；不得为实体按键映射压缩内容区 |
| 交互 | 触摸与实体按键可以并存，但原型不定义按键数量、位置、编号、短按或长按映射 |
| 底部 | 禁止实体按键提示、网页式底栏、`返回 / 确认 / 翻页`伪栏 |
| 状态 | ANT+、蓝牙、定位等须使用可识别图标；连接状态不显示协议文字；风险不可只用颜色表达 |

骑行中仍遵循**一眼原则**：每页只允许一个第一视觉重点——核心数值、转向指引或风险状态三选一。High fidelity 不能以牺牲阳光下的识别速度为代价。

## 2. 视觉语言：Night Vector

### 2.1 气质与结构

- **High-design hardware UI, low-ego language.** 像一台被认真打磨的高性能设备，而非一张炫技手机海报。
- 使用深墨绿黑的低反射表面、冷白数字、细密边界和受控的局部光晕建立材质感。
- `Volt` 是唯一的行动与当前焦点颜色；`Route` 只用于定位、路线与导航；警告色只服务于真实风险。
- 数字优先于卡片。层次来自字号、对比、留白、细线与微趋势，而不是一层层悬浮卡片。
- 每个页面的颜色预算为：`1 个 Volt 焦点 + 0 或 1 个语义状态色 + 中性色`。不要彩虹数据墙。

### 2.2 明暗策略

LowDesign 只批准 `dark` / `n-a` 模式。深色不是把所有层涂黑：画布、容器、浮层、边界、文字和弱文字必须彼此可分辨。

- 常态数据：墨黑表面 + 冷白数字 + 静默中性色标签。
- 当前操作 / 核心进度：Volt 局部线、图标、短条或数字强调；不使用整屏荧光底。
- 导航：Route 蓝承担路线与定位；不与 Volt 同时作为第二个大面积焦点。
- 风险：使用 Warning / Alert 的图标、局部色带和短标签；不让告警遮蔽主数据。

## 4. 组件语法

### 4.1 状态栏 `LowDesign/StatusBar/System`

- 固定 `32px` 高，使用 `low/color/bg/system` 与 `low/color/border/subtle`。
- 左边仅时间；右边为必要状态图标组，再接电量图标与百分比。
- 图标常态为 `low/color/text/muted`；异常可使用语义色，但页面内容必须同步给出可理解的短提示。
- 禁止协议文字、通知文字、圆点替代图标与设备名。

### 4.2 主数据 `LowDesign/Data/MetricHero`

- 一个页面只能有一个 Hero；使用 `low/font/data/hero` 和 `low/color/text/primary`。
- 单位贴紧主数值；标签在数值上方；可选的微趋势线或进度细条在下方，不与数字竞争。
- Volt 只作为单位、细进度、图标或选中数据的局部强调。

### 4.3 精密数据格 `LowDesign/Data/PrecisionCell`

- 双列格以 `low/color/border/subtle` 划分，不加大圆角卡片、不投厚重阴影。
- 格内只表达一个数据主题：标签 → 数值 → 单位；非关键数据不得使用高饱和色。
- Variant：`Default`、`Focused`、`Muted`、`Warning`、`Alert`；状态 Variant 必须同时含图标或短文案。

### 4.4 微趋势 `LowDesign/Data/MicroTrend`

- 只作为数据变化的第二层信息，不替代文字数值。
- 默认采用低饱和填充与 `low/color/action/primary` / `low/color/nav/route` 细描边；无数据时使用明确的空态符号和短标签。

### 4.5 导航转向 `LowDesign/Navigation/TurnCard`

- 转向成为页面主角时，使用 `low/color/nav/route` 图标与路线信息；不能与 Volt Hero 同时争夺视觉重点。
- 使用最短距离、转向方向和必要道路/路线状态。定位失败、未加载路线、已偏航需各自有图标 + 短标签 + 语义色。

### 4.6 风险与雷达 `LowDesign/Safety/RiskCallout`

- 使用局部色带、图标、风险词和必要方向；不覆写整屏背景。
- `Warning` 表示需要注意，`Alert` 表示危险 / 阻止；它们不能用于普通连接、选中或装饰。
- 风险等级变化只改变风险区域，不让普通数据格位移、换色或跳动。

### 4.7 系统提示、列表与进度

- `SystemPrompt`：居中图标 / 多语言图片 + 短标题；表面可使用 `low/radius/panel`，但不添加底部实体按键提示。
- `SelectionList`：深底、细线、单行主文本，可选极短副文本；焦点为 Volt 描边或弱面，不能只改变文字颜色。
- `Progress`：用明确进度、阶段词和防误触状态；OTA 对用户始终是一项整体任务，不暴露芯片 / 差分等实现细节。

## 5. 页面模板与颜色预算

| 模板 | 唯一视觉主角 | 允许的强调色 | 禁止事项 |
| --- | --- | --- | --- |
| `Ride Live` | 当前速度 / 关键骑行数据 | Volt；可选一个语义风险色 | 多个同等大数字、彩色数据墙 |
| `Navigation` | 转向指引或路线 | Route；可选 Alert | Route 与 Volt 同时大面积抢焦点 |
| `Risk / Radar` | 风险状态与方向 | Warning 或 Alert；Route 可辅助方向 | 把所有普通格改成风险色 |
| `Ride Summary` | 一个本次结论或成绩 | Volt 或 Success | 像 App 首页一样堆叠多张大卡 |
| `Settings / System` | 当前选择或系统状态 | Volt；语义状态仅在需要时 | 运动数据 Hero、未确认按键映射 |

## 6. 高保真边界

### 必须具备

- 真实的 Default、Focused、Loading、Empty、Success、Error / Alert 状态，且主数据、单位和时间不使用占位符混过去。
- 一致的数字字形、线宽层次、暗面分层、状态图标、局部微趋势或进度；所有细节均可追溯到 Token。
- 每个动效都有静态等价状态；停止动画后信息仍能在一眼内读懂。
- 在阳光 / 灰阶视图中，主数据、导航和风险仍由对比、形状、位置和文字共同区分。

### 禁止事项

- 无限循环发光、霓虹渐变背景、只为装饰的 3D、低对比小字和假玻璃拟态。
- 手机底部导航、滚动卡片流、网页按钮条、实体按键映射和未确认的硬件能力。
- 以颜色编码所有数据；警告与错误不能只靠颜色，也不能成为普通正文色。
- 将 Pixso 或外部概念稿的圆形硬件、边缘触控、复杂语音交互直接搬入 C706。


生成或评审前必须声明：`canvas = low/color/bg/canvas`、`primary = low/color/action/primary`、`route = low/color/nav/route`。组件不直接使用 Primitive 值。

## 8. 交付自检

- [ ] 目标已明确选择 LowDesign；不是默认替换 C706 正式系统。
- [ ] Frame 为 `320 × 480px`，高度预算为 `32 + 448 = 480`。
- [ ] 状态栏为时间左 / 图标组右 / 电量最右；没有协议文字和假图标。
- [ ] 没有滚动、底部伪栏或实体按键映射。
- [ ] 每个骑行页只有一个 Hero，颜色预算没有超标。
- [ ] 风险同时通过图标 / 文案 / 颜色中的至少两种表达。
- [ ] 高保真细节服务数据和状态，不是装饰噪音；静态截图仍然可用。
- [ ] 未确认的硬件、通信和自动行为已标为待确认。
