# 迈金设计规范

> 当前以 C706（320 × 480px）为主要适配机型；后续其他迈金码表需补充独立的屏幕与硬件约束。

## 1. 设计语言

C706 是固定 `320 × 480px` 的骑行码表。视觉目标是浅色、高对比、稳定、数据优先；骑行中遵循“一眼原则”：先看到最重要的数据、转向或风险，再阅读标签和次级信息。

- 这是 C706 的正式规范，不适用于其他分辨率机型。
- 触摸和实体按键可以并存，但原型不定义按键数量、编号、位置或短长按映射。
- 页面不滚动，不设置底部按键提示栏，也不把 App 的卡片式大圆角直接搬到数据页面。

## 2. 物理画布与页面骨架

| 区域 | 尺寸 | 规则 |
| --- | --- | --- |
| 系统状态栏 | `320 × 32px` | 固定顶部 |
| 内容区 | `320 × 448px` | 无滚动、无底部伪栏 |
| 子页面标题栏（可选） | `320 × 48px` | 位于内容区顶部；余下主体 `400px` |

```text
Y=0–32      System Status Bar
Y=32–480    Content
  ├─ 可选 Y=32–80  Page Header
  └─ 页面主体
```

内容未填满时，只能作为多语言、触摸热区、状态安全区、视觉留白或已确认预留槽位；不得用横线或底色制造底部操作区。

## 3. Token

### 3.1 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `c706/color/bg/base` | `#FFFFFF` | 内容区、数据格 |
| `c706/color/bg/system` | `#F1F5F9` | 顶部状态栏 |
| `c706/color/text/primary` | `#334155` | 核心文字、数值 |
| `c706/color/text/muted` | `#64748B` | 标签、单位、弱提示 |
| `c706/color/border` | `#94A3B8` | 1px 分割线 |
| `c706/color/action/focus` | `#2563EB` | 当前焦点、选中、可执行主操作 |
| `c706/color/action/focus-bg` | `#DBEAFE` | 当前选择背景 |
| `c706/color/status/success` | `#2CC683` | 正常、完成、已连接 |
| `c706/color/status/warning` | `#FFA423` | 低电量、需要注意 |
| `c706/color/status/error` | `#F14867` | 风险、失败、阻止 |

常态骑行数据保持白底深色数值；状态色只用于建立优先级，不给每个数据格随意着色。

### 3.2 字体、间距、图标与边界

- 标签和说明使用清晰的无衬线字体；数字优先使用等宽或数字字体。
- 页面标题 `24px Semibold`，模块标题 `18px Semibold`，正文 `16–18px`，辅助文字 `12–14px`；核心数值优先 `32px` 以上。
- 数据格与列表使用直角边界和 `1px` 分割线；仅居中提示、确认浮层可以使用 `8px` 圆角。
- 状态图标用可识别的 ANT+、蓝牙、定位、电量等图形；没有正式资产时保留图标占位和图层名，不用圆点或文字代替。

## 4. 状态栏、标题和触摸

### 4.1 系统状态栏

信息顺序固定：

```text
左：时间                         右：状态图标组  电量图标与百分比
```

- 时间始终在左侧；电量图标和百分比始终在最右侧。
- ANT+、蓝牙、定位等状态图标紧挨电量左侧横向排列。
- ANT+/蓝牙存在连接设备时仅显示图标，不显示“ANT+”“BLE”“已连接”等文字。
- 状态栏不放设备名称、通知或复杂状态解释；异常需要在内容区给出图标或短提示。

### 4.2 子页面标题与操作

- 标题栏高度 `48px`；标题过长时缩短，不换两行。
- 只有需求明确时显示返回入口。
- 确认、返回、下一步等动作必须作为内容区中的已确认触摸入口表达。
- 不在屏幕底部展示 A/B/C、左右键、返回、确认、翻页等按键映射，也不预留该区域。

## 5. 核心组件与页面模式

| 组件/页面 | 规格与使用方式 |
| --- | --- |
| Data Cell | 通栏 `320 × 102px`；双列 `160 × 81px`；数据包含标签、数值、单位，数值过长缩小不折行 |
| 数据墙 | 首行通栏 `80px`，其余双列单元 `82px`；每格只表达一个数据主题 |
| 选项列表 | 单行主文案，可选一行极短辅助信息；当前项使用焦点色和淡蓝背景共同表达 |
| 系统提示 | 居中图标或本地化图片 + 短标题；避免长段说明 |
| 确认/恢复 | 涉及数据或恢复风险时使用产品已确认的图片文案；原型标注“多语言图片文案” |
| 骑行风险提示 | 核心风险使用局部色带、图标或关键数据强调；不遮挡主数据，不持续改变其他区域布局 |

## 6. 一眼原则

- 每页只设一个第一视觉重点：核心数值、转向指引或风险状态三者之一。
- 标签短，单位贴近数值；次级数据可快速定位但不与主数据抢层级。
- 非关键数据刷新时不改变位置、大小或颜色，避免骑行中视觉跳动。
- 不在骑行页放长说明、多个同权重按钮或多段帮助文案。

## 7. 固件任务表达

- OTA 以一次整体任务表达，不向用户展示主芯片、从芯片、差分包或分区。
- Recovery 成功后码表自动重启并回到首页；不保留“继续”或“返回”按钮。
- 从节点更新失败时显示“升级失败”和已确认的重试入口；不进入 Recovery。
- Recovery 失败只使用已确认的失败图片或短提示，不编写超长故障说明。

## 8. C706 自检

- [ ] Frame 为 `320 × 480px`，高度预算为 `32 + 448 = 480`。
- [ ] 状态栏为“时间左 / 图标组右 / 电量最右”。
- [ ] 无滚动、无底部伪操作栏、无实体按键映射。
- [ ] 数据页符合一眼原则，文字短且状态不只依赖颜色。
- [ ] 组件采用 C706 的直角数据格与分割线语言。
- [ ] 升级和恢复按已确认的用户可见流程表达。
