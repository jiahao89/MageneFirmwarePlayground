# Pen.dev 适配

先运行 `$magene-design` 并读取目标系统规范。本文件只约束画布、连线与命名，不定义目标系统的视觉样式。

## 画布

- 按 `系统 → 页面/组件 → 状态` 分组，避免将顽鹿 App、C706 和 GEOID 的 Frame 混排。
- C706 和采用 C706 平台的 GEOID 使用 `320 × 480px` 画布；页面内不创建用于实体按键映射的底部区域。
- 原型页保留状态边界和跳转，组件页只保留可复用组件与 Variant。

## 连线

- 连线从用户实际操作的页面或控件发出，指向用户下一眼会看到的页面或状态。
- 正常路径实线；已确认异常路径虚线；未确认路径不连线，改为旁注“待确认”。
- 跨端流程中 App 与码表分栏排列，避免把两端 Frame 拼合为一张页面。

## 命名与检查

- Frame：`[系统] / [端] / [页面] / [状态]`。
- 组件：`[系统] / [类别] / [名称] / [Variant]`。
- 截图前检查目标系统、画布尺寸、状态栏、状态 Variant、页面回归路径和待确认标注。
