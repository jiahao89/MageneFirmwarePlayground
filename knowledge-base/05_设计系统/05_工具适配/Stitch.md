# Stitch 适配

先运行 `$magene-design` 并读取目标系统规范。本文件只约束 Stitch 提示词和产出检查，不能覆盖目标系统的视觉 Token。

## 提示词必须包含

```text
目标系统：顽鹿 App / 迈金 C706 / GEOID
目标端与尺寸：例如 C706 320 × 480px
显示模式：Dark / Light / Both
页面目标、用户操作、状态与跳转
必须使用的 Token、组件和硬约束
不允许出现的元素：例如 C706 底部按键映射
```

## 产出约束

- 一次只生成一个明确页面或状态，不用模糊的“做一个码表界面”。
- 顽鹿 App 任务页不生成底部一级导航；C706 不生成网页式底部操作栏或滚动容器。
- GEOID 明确模式后再生成，不混入顽鹿 App 的荧光黄绿色或 C706 的浅色数据格语言。
- 生成后按目标规范逐项检查 Token、尺寸、状态和可用操作；不符合时按具体问题重做。
