# GEOID 极遨设计规范

## 1. 设计语言与适用边界

GEOID 是独立品牌，不等同于任何具体机型。它的设计语言是**年轻、多彩、活力、趣味、低门槛**：优先让减脂健身、社交休闲和城市通勤用户在一眼内理解当前状态和下一步，而不是把专业数据堆满首页。

- 每次设计先确认具体机型和尺寸；仅当机型明确采用 C706 平台时，才使用 `320 × 480px`、顶部 `32px` 状态栏和无底部操作栏的物理规则。
- 每个页面必须明确 **Dark / Light / Both**。深色对应全透屏，浅色对应半反半透屏；高保真 Token 和关键页面同时维护两套色值。
- 码表的渲染约束优先：只使用纯色填充；禁止渐变、发光、弥散阴影和毛玻璃。
- GEOID 的装饰不替代数据可读性、状态表达、物理屏幕限制或交互边界。

### 2.2 字体、间距、圆角与图标

| 类别 | 规范 |
| --- | --- |
| 文本字体 | 思源黑体 Medium，用于标题、标签、说明、按钮；不使用装饰字体 |
| 数字字体 | Objectivity-Bold，用于时间、距离、功率、心率等全部数据数值；未交付时用系统无衬线 Bold，并标注“数字字体待替换” |
| 文本层级 | H1–H7：12/16、14/19、16/22、18/25、20/28、22/30、24/33 px；数字 N1–N18：14–96px，按数据优先级选择 |
| 间距 | 2 / 4 / 6 / 8 / 12 / 16 / 20 / 24px；所有间距使用 2 的倍数 |
| 圆角 | 8 / 16 / 20px；按钮、标签、信息卡可圆角，数据格、表格和状态栏是否圆角由机型决定 |
| 图标 | 16 / 18 / 22 / 24 / 32 / 40 / 48 / 56 / 64 / 72 / 80 / 120px；同层级统一圆润的线性或填充语言 |

数字与单位基线对齐。正式 Logo、插画和图标未交付时只使用清晰的几何占位并标记“品牌资产待替换”，不用 emoji 或字符图标。

## 3. 品牌图形与视觉纪律

GEOID 可使用两个辅助图形：**地平线线条**与**双线段断点**。

- 每页最多使用 1–2 处，优先用于 Header、进度条、图标内部或空状态插画。
- 它们是识别点缀，不是页面结构；不能遮挡数据、状态文案和操作入口。
- 首页、设置页、提示页可采用轻量卡片与留白；数据墙、表格、系统状态栏和设备级列表仍按目标机型的结构组织。
- 切页指示器采用圆角短矩形（如 `12 × 4px`），不用传统小圆点。
- 胶囊按钮和状态标签可采用高度 `40px`、圆角 `20px` 的形式；一个页面最多一个最强主操作。

## 4. 页面与组件

| 类型 | 规则 |
| --- | --- |
| 首页/骑行概览 | 明确一个核心数据或状态；新手主界面不堆叠专业曲线和深层配置 |
| 数据墙 | 核心指标最大且最高对比；次级指标层级降低；机型确定后遵守其数据格、边界和高度预算 |
| 列表/设置 | 用短标题和直观图标降低理解成本；复杂专业项下钻，不干扰基础操作 |
| 卡片/面板 | 可用大圆角和纯色底分组；不使用阴影、模糊或渐变来制造层级 |
| Dialog | 说明当前决定、影响和下一步；危险操作不与常规操作视觉等权 |
| Empty / 成就 / 完成 | 可使用轻量趣味插画或品牌图形，但必须保留清晰标题、结果和下一步 |
| 连接/同步/任务 | 每个状态单独建立 Frame，避免把成功、失败、加载堆在一页 |

涉及异步任务时，按适用性建立：`Default`、`Loading`、`Empty`、`Disabled`、`Success`、`Error`。失败页包含短原因和需求确认过的重试、返回或关闭入口；无法确认的恢复逻辑只标“待确认”。

## 5. GEOID 码表与 C706 平台的关系

若 PRD 确认 GEOID 页面运行在 C706 同一物理平台，额外遵守：

- Frame 为 `320 × 480px`，顶部状态栏 `32px`，内容区 `448px`；无滚动、无底部按键映射。
- 状态栏为“时间左 / 必要状态图标紧邻电量左侧 / 电量最右”；ANT+、蓝牙等只显示图标。
- 数据格、表格和高密度骑行页优先使用清晰结构与稳定边界；GEOID 品牌色和圆角只作适度强化。
- 骑行中每页只放一个第一视觉重点，风险使用图标、短文案和局部色共同提示。

如果机型不是 C706 平台，必须先补充其屏幕尺寸、状态栏、内容区、是否触摸、是否支持滚动和按键约束，再生成高保真页面。

## 6. 多语言、动效与交付

- 支持 20 种语言时，设计稿优先用最长翻译验证布局；超过空间时按“缩小一个层级 → 允许缩写（记录规则） → 截断（标注位置）”处理。
- 文案只传达一个动作或状态，避免新手理解专业术语；专业配置应下钻或折叠。
- 动效基调为弹性、跳跃、渐进缩放；原型阶段用静态关键帧表达。具体时长、帧率、缓动和性能降级未确认前不写成实现承诺。
- Frame/组件命名：`GEOID / [端] / [页面或组件] / [状态]`。

- [ ] 数字使用 Objectivity-Bold 或已标注占位；文本使用思源黑体 Medium。
- [ ] 深浅两种模式均有相应 Token；关键文本和状态在目标模式中可读。
- [ ] 只使用纯色填充，没有渐变、发光、毛玻璃或阴影。
- [ ] 每页的品牌图形不超过 1–2 处，且不影响数据和操作。
- [ ] 适用的默认、加载、空、禁用、成功、失败状态已独立表达。
- [ ] 若使用 C706 平台，已满足其物理尺寸、状态栏和无底部映射约束。
