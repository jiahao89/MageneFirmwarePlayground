# MFP 知识层导航

> MFP 的知识层是从 `Magene_PM_Workspace` 提取的可复用方法论，与原始 PRD 历史（留在 workspace）分离。
> **workspace 是唯一事实源，本目录不持有原始 PRD；workspace 中的知识页更新后，可按下方映射表手动重新同步。**

## 目录结构

| 目录 | 内容 | 何时用 |
|------|------|--------|
| `00_规范与模板/` | PRD 编写规范、轻量/复杂两套模板、术语表 | 写 PRD 时 |
| `01_事实源/` | BENCHMARK（SSOT 索引）、知识库总索引、机型版本功能矩阵 | 开工前召回事实 |
| `02_竞品/` | 竞品对标框架（四品牌 + 三层拆解模板） | 调研时 |
| `03_人群与方法论/` | 6 层人群模型、评审能力边界 | 归位与评审分工 |
| `04_知识页/` | 车灯等已沉淀专题知识页 | 查专题基线 |
| `05_设计系统/` | 顽鹿App/C706/GEOID 三套设计规范 + 路由（唯一正式规范） | 出原型前 |
