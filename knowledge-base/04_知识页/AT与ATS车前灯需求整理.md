# AT 与 ATS 车前灯需求整理

> 整理日期：2026-07-15  
> 范围：整理当前资料中关于 **AT** 与 **AT S / ATS** 车前灯的产品、码表接入、App 设置、表盘与智联需求。  
> 口径说明：`AT S` 与 `ATS` 当前按同一类车前灯理解；文档中主要写法为 `AT S`、`AT S1200/1600`。若后续硬件命名确认不同，需要再拆分。

## 1. 是否已有需求描述

结论：**有，但完整程度不同。**

| 类型 | 当前资料覆盖情况 | 主要来源 |
| :--- | :--- | :--- |
| AT 系列智能前灯 | 有完整产品 PRD，覆盖硬件、协议、档位、亮度衰减、续航、App/码表/智能按键连接、埋点 | `02_历史归档/车灯与前灯/AT系列智能前灯 PRD.md` |
| AT S / ATS 前灯 | 有码表接入、蓝牙连接、低电量、车灯表盘、智联条件/动作描述；未找到独立完整产品规格 PRD | `PV3.2版本需求PRD.md`、`迈金C706.md`、`迈金码表全功能整合PRD_V2.md`、`01_工作台/专项PRD/APP端/APP端码表设置专项PRD-整理版.md` |
| AT PRO | C706 1.8 中有一段“AT Pro 车灯适配”，但标题标注“暂时取消” | `02_历史归档/C706/C706 1.8版本需求PRD.md` |

| 电池容量 | 4000 mAh | 5000 mAh | 5000 mAh |
| 芯片 | Nordic 52832 | Nordic 52832 | Nordic 52832 |

| 厂商字段 | 107 | 107 | 107 |

### 2.2 连接对象

AT 系列明确支持：

- 连接 **顽鹿运动 / OnelapFit App**：查看设备信息、自定义档位、开关灯、切换档位、固件升级。
- 连接 **智能按键**：通过默认指令或自定义按键指令控制车灯。
- 连接 **迈金码表**：码表控制开关灯、切换档位，展示车灯电量与剩余续航。
- 连接其他支持 ANT+ 车灯的码表：主要是设备信息、开关、电量等标准能力。

### 2.3 码表侧适配

| 能力 | 当前需求 |
| :--- | :--- |
| 搜索/保存/连接 | 5、6 系码表以外设连接方式连接；4 系历史资料提到通过码表 App 主页、ANT 通道搜索前灯 |
| 设备详情 | 支持查看设备信息、电量等 |
| 表盘数据项 | 车灯电量、剩余续航时间 |
| 表盘控制 | 开/关灯、切换档位，部分方案包含一键 SOS |
| 智联 | 5 系及以上码表可通过智联指令让前灯响应档位切换或开关灯 |

## 3. AT 系列档位、亮度与保护逻辑

### 3.1 档位能力

- 最多支持存储 **10 个档位**。
- 预置档位包含：低亮、中亮、高亮、日间闪烁、夜间闪烁、呼吸等。
- 支持自定义：常亮、闪烁、呼吸。
- 档位记忆：开机后响应上次关机前的亮灯档位。
- 切换方式：车灯电源键、App、智能按键、码表。

### 3.2 常亮亮度

| 常亮档位 | AT800 | AT1200 | AT1600 |
| :--- | :--- | :--- | :--- |
| 低亮 | 200 lm | 400 lm | 400 lm |
| 中亮 | 400 lm | 800 lm | 800 lm |
| 高亮 | 800 lm | 1200 lm | 1600 lm |

### 3.3 目标续航

| 档位 | AT800 | AT1200 | AT1600 |
| :--- | :--- | :--- | :--- |
| 日间闪烁 | 20h | 25h | 25h |
| 夜间闪烁 | / | 50h | 50h |
| 呼吸 | 25h | 30h | 30h |
| 低亮 | 8h | 10h | 9h |
| 中亮 | 4h | 3.5h | 3h |
| 高亮 | 2h | 2h | 1.2h |

### 3.4 温度、电量、充电保护

| 条件 | 处理 |
| :--- | :--- |
| 温度 > 70℃ | 预置常亮降至低亮档，闪烁/呼吸与自定义档位降至 40% |
| 温度 > 80℃ | 闪烁 3 次后强制关机 |
| 电量 < 20% | 预置常亮以低亮档运行，闪烁/呼吸与自定义档位降至 40% |
| 电量 < 2% | 除 SOS 外，闪烁 3 次后强制关机 |
| 充电时 | 预置常亮以低亮档运行，闪烁/呼吸与自定义档位降至 40% |
| 优先级 | 充电 > 温度 > 电量 |

### 3.5 光通量衰减

AT1200 / AT1600 文档明确：开机正常亮度运行 3 分钟，3 分钟后开始衰减，并在 2 分钟内由当前亮度线性衰减至 60%。

> 注意：该逻辑在文档中注明“不可对外宣传”。

## 4. AT S / ATS 当前需求

### 4.1 设备识别与连接

当前资料提到的 AT S 设备：

- `AT S1200/1600`
- `AT S 智能自行车前灯`

在 PV3.2 传感器列表页中，迈金生态设备包括 `AT1200/1600` 与 `AT S1200/1600`，连接后需要展示品牌 + 设备名称。

### 4.2 蓝牙连接方向

PV3.2 中有“车灯改为蓝牙连接前灯和尾灯（不再组网）”章节，但该章节标注 **延后至 PV3.3 处理**。其中明确提出：

- 后续车灯不再做 ANT+ 组网，采用蓝牙方式连接。
- 区分 **前灯** 和 **尾灯** 两种类型。
- AT、AT S 车灯需完成蓝牙协议下适配，包含连接和控制。
- 目标：连接更快、更稳定，支持同时连接前灯和尾灯。

因此当前口径应为：

| 项目 | 状态 |
| :--- | :--- |
| AT / AT S 作为前灯类型接入传感器体系 | 已有描述 |
| AT / AT S 蓝牙独立连接方案 | 有明确规划，但 PV3.2 文档标注延后至 PV3.3 |
| 是否已落地 | 需按实际固件版本确认 |

### 4.3 低电量提醒差异

PV3.2 / App 端码表设置资料中对蓝牙前灯低电量阈值有区分：

| 设备 | 首次提醒 | 二次提醒 |
| :--- | :--- | :--- |
| AT 前灯 | 电量低于 30% | 电量低于 10% |
| AT S 前灯 | 电量低于 20% | 电量低于 10% |

弹窗规则：

- 弹窗位置：底部弹出。
- 弹窗可点击【知道了】关闭，或 5 秒后自动关闭。
- 文案结构：`类别 + 名称 + 电池电量低`。
- 触发低电量弹窗时，同时触发“传感器电量低”语音播报。
- 多个设备同时触发时，仅播报一次。

### 4.4 车灯表盘

PV3.2 中有 “车灯表盘（AT、AT S、L308、L508）”，但标注 **延后至 PV3.3 处理**。

已描述的方案：

| 能力 | 要求 |
| :--- | :--- |
| 自定义模式数量 | AT、AT S 最多支持自定义 10 种灯光模式 |
| 模式 = 6 个 | 按当前车灯表盘展示 |
| 模式 < 6 个 | 未自定义模式置灰 |
| 模式 > 6 个 | 模式 6 改为【更多】，弹浮层展示更多模式 |
| 关灯状态 | 不允许切换模式；不能通过点击模式开灯 |
| 开灯默认 | 默认打开灯光模式 1 |
| 关闭逻辑 | 只能通过开关控制，不支持重复点击同一模式来开关 |
| SOS / 爆闪 | 普通模式、爆闪、SOS 之间不应互相误关灯；关闭爆闪/SOS 后应回到原模式或设备规则状态 |

### 4.5 AT S 独有控制点

整合稿和 C706 体验笔记中均提到：

| 设备 | 智联条件 | 智联动作 |
| :--- | :--- | :--- |
| AT1200 / AT1600 | 灯亮时、电量、灯灭时 | 打开车灯、关闭车灯、打开/关闭车灯、灯光模式设置 |
| AT S | 灯亮时、电量、灯灭时 | 打开车灯、关闭车灯、打开/关闭车灯、打开/关闭爆闪/SOS、灯光模式设置 |

差异点：**AT S 多了打开/关闭爆闪/SOS 能力**。

## 5. AT PRO 需求状态

C706 1.8 文档中存在 `AT Pro 车灯适配（暂时取消）`，包含：

- AT1200 PRO、AT1600 PRO；
- 支持 ANT+、蓝牙双模式；
- 适配 C706、C606 V2、C606 Pro、C606、C506；
- 搜索、记住、连接、忘记；
- 低电量提醒；
- 车灯电量、续航数据项；
- 模式控制、一键 SOS、一键爆闪；
- 智联条件/动作增加 AT PRO。

但标题明确标注 **暂时取消**，因此不能按已实施需求处理。

## 6. 当前结论

| 问题 | 结论 |
| :--- | :--- |
| 文档中有没有 AT 前灯需求？ | 有，且 AT 系列产品 PRD 较完整。 |
| 文档中有没有 ATS / AT S 前灯需求？ | 有，但主要是码表接入和控制能力，未找到独立完整产品规格 PRD。 |
| AT 和 AT S 是否都作为前灯接入？ | 是，PV3.2 和整合稿均将 AT / AT S 作为前灯类设备。 |
| 新平台是否要蓝牙连接 AT / AT S？ | 有明确规划，但 PV3.2 标注延后至 PV3.3。 |
| AT S 与 AT 的主要差异是什么？ | 当前资料明确差异主要在低电量阈值和爆闪/SOS 控制能力。 |
| AT PRO 是否要算进当前需求？ | 不建议，C706 1.8 标注“暂时取消”。 |
