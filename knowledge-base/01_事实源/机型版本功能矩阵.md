# 机型版本功能矩阵

> 整理日期：2026-07-15  
> 整理目的：作为理解迈金码表功能、版本差异、机型裁剪的稳定入口。  
> 口径说明：本表只沉淀历史文档中已明确的信息；若文档标注待定、删除线、延后或来源冲突，统一标为「待确认 / 延期 / 不支持」，不做推断。

## 1. 状态标记

| 标记 | 含义 |
| :--- | :--- |
| ✅ | 已明确支持 |
| 🟡 | 有明确资料支持，但仅部分机型 / 版本 / 协议支持，或存在明确裁剪 |
| ⏳ | 规划中、延期、后续版本处理 |
| ❌ | 明确删除或不支持 |
| ？ | 当前资料不足，不能判断支持或不支持；不能用推测替代 |

> 使用原则：`🟡` 不是“可能支持”。如果只是按产品常识觉得应该有，但没有在当前资料中找到明确证据，应标为 `？`。

## 2. 来源优先级

1. 单版本原始 PRD 优先于整合稿：例如 `C706/C606Pro/C606V2海外2.1版本需求文档`、`PV3.2版本需求PRD`、`迪卡依GPS EDR码表需求PRD`。
2. 整合稿用于建立全局口径：`01_工作台/迈金码表全功能整合PRD_V2.md`。
3. 专项文档用于补充单模块边界：例如 `海外2.1固件支持传感器清单.md`、`车灯码表适配需求.md`、`CC750_750P 交互设计.md`。
4. 删除线、待定、延后到下一版本的内容，不能写成当前已支持。

## 6. 版本差异重点

### 6.1 C706 国内 1.5-2.0

- 资料已补齐 `C706 1.5` 到 `C706 2.0` 多份 PRD。
- 当前知识库还缺一份「逐版本变更表」，用于回答“某功能从哪个版本开始支持、哪个版本调整文案/逻辑”。
- 现阶段可把 C706 视为 5 系存量主线：有 Wi-Fi、星环灯、5 按键、成熟传感器/导航/表盘能力。

### 6.2 C706 / C606 Pro / C606 V2 海外 2.1

- 明确面向 C706、C606 Pro、C606 V2 海外版。
- 传感器明确覆盖 12 类：心率、速度/踏频、功率、骑行台、雷达、电子变速、Magene 电子变速、前灯、尾灯、DJI 相机、Insta360 相机、Core。
- 新增/变化重点：Core、SRAM 电变控制码表、标准蓝牙 FTMS、DJI Action 6、Insta360 X6、蓝牙传感器电量百分比、回连逻辑优化。
- 注意：海外 2.1 不含 Aerosensor；GoPro、呼吸传感器也不是海外 2.1 已支持项。

### 6.3 PV3.2 / C716 / C716 Pro

- PV3.2 是新平台系统级能力集成版本，覆盖地图、导航、赛段、爬坡、传感器、数据传输、码表设置、电源管理、消息通知等。
- C716/C716 Pro 明确取消 Wi-Fi，使用蓝牙共享网络。
- 传感器详情页、连接数量、电量显示、低电量提醒有更完整的 PV3.2 定义。
- 车灯蓝牙独立连接、车灯表盘、首页传感器冲突处理、CP 电变/GoPro/Aerosensor/呼吸传感器等，文档中存在延后或删除线口径，需按延期/待确认处理。

### 6.4 Mars

- Mars 已有 V0.030、V1.1、V1.2、V1.3、Mars Pro V1.3 文档。
- 已知有省电优化、传感器扫描优化、连接回连等专项逻辑。
- 当前缺一份 Mars 与 C706/C716 的横向能力对照表，尤其是导航、传感器、车灯、表盘、固件升级范围。

### 6.5 CC750 / 750P

- 当前资料以交互设计为主。
- 明确硬件交互：3.3 英寸 320x480，3 个底部软皮按键，支持触屏。
- 非骑行记录状态以触屏为主；骑行记录状态支持触屏 + 按键。
- A 键：短按计圈，长按开关机/电源管理；B 键：开始/继续/暂停，长按结束记录，首页快速开始；C 键：短按翻页，长按车铃。
- 还缺完整功能能力表。

### 6.6 迪卡侬 EDR

- EDR 是基于 C606 Pro 海外 2.1 的 To-B 定制，初始固件 2.100。
- 新增：自行车防盗、HRV、主题色、首页调整、负一屏调整、定制开机动画。
- 删除：激活、背光、智联、模拟路线、骑行动态、团队骑行、风向收益、Core 核心温度计等。
- 防盗依赖加速度计、蜂鸣器、屏幕红框/高亮、App 蓝牙连接告警；HRV 依赖 App 计算并同步，码表端展示。

## 7. 当前最影响理解的资料缺口

| 缺口 | 影响 | 建议补齐方式 |
| :--- | :--- | :--- |
| 硬件能力矩阵 | 无法准确判断各机型哪些功能是硬件受限，哪些只是版本未做 | 建一张 `机型-芯片-屏幕-按键-传感器-无线能力` 表 |
| 逐版本变更表 | 难回答“某功能从哪个版本开始支持” | 先做 C706 1.5-2.0，再做 Mars 版本链 |
| 协议 / 接口规格 | 传感器、车灯、相机、电变的 App/固件/协议边界仍分散 | 建 `传感器协议与数据字段索引` |
| FIT 字段矩阵 | Core、骑行动态、传感器信息、EDR 删除项会影响 FIT 兼容 | 建 `FIT字段与版本兼容矩阵` |
| BOSS / 后台 / 云端配置 | App 同步、账号、位置点、固件升级、消息通知依赖后端，但资料较少 | 收集后台配置、云端接口、灰度策略文档 |
| OTA 安全机制 | 断电保护、回滚、双分区、失败恢复口径不足 | 向固件确认升级状态机和异常处理 |
| 测试矩阵 | 功能有 PRD，但验收用例和覆盖范围分散 | 为传感器、导航、固件升级、设置同步建立测试基线 |
| UI 原型索引 | 大量 PRD 引用飞书/Pixso，离线文档缺少原型索引 | 建 `原型与设计稿索引.md`，标注页面、机型、版本 |
| 用户反馈 / 售后问题 | 功能价值判断缺少真实反馈闭环 | 汇总客服、论坛、灰度反馈、Bug 列表 |

## 8. 推荐下一步沉淀
