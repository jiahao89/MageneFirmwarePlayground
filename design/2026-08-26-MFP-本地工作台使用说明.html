02 / IDENTITY

谁才是“产品经理 Agent”

MFP PM Agent 不是在 Claude Code 里重新创建一个模型，也不只是提示词包装器。它由规则、知识、技能、状态、任务卡、工作包和人工门禁组成，能够在边界内判断下一步并推进需求。

06 / HANDOFF

真实协作：谁在哪一步操作

Web 是 PM 的正式操作台；Claude Code 是 Agent 的执行现场。MFP 不把 Web 变成另一个聊天窗口，而是通过工作包同步事实、问题、回答和产物。
